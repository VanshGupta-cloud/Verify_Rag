# Phase 1 Plan: Milestone 1 Ingestion & Vector Retrieval Layer

## Objective
Establish the document processing and vector retrieval foundation for VerifyRAG:
1. Centralized configuration with Pydantic v2 BaseSettings.
2. Multi-format document parser (`.pdf`, `.txt`, `.md`).
3. Recursive character text splitter (500-char chunk size, 50-char overlap).
4. FAISS dense vector store wrapper with singleton embedding caching and top-$k$ retrieval returning canonical `Chunk` instances.

## Execution Waves

### Wave 1: Foundation & Schemas
- **Task 1.1:** Create `src/__init__.py`, `src/schemas.py` containing the canonical Pydantic v2 schemas defined in `brain.md` (`VerdictEnum`, `Chunk`, `Claim`, `LatencyBreakdown`, `VerificationResult`).
- **Task 1.2:** Create `src/config.py` using `pydantic-settings` to manage thresholds (`entailment_threshold=0.70`, `contradiction_threshold=0.60`), top-$k$, device selection (`cuda`/`cpu`), model names, and API keys.

### Wave 2: Ingestion Engine
- **Task 2.1:** Create `src/ingestion/__init__.py` and `src/ingestion/parser.py`:
  - Functions: `parse_document(file_path: Union[str, Path]) -> ParsedDocument`, `extract_text_from_pdf(path: Path) -> str`, `extract_text_from_txt(path: Path) -> str`.
  - Robust UTF-8 handling with latin-1 fallback.
  - Multi-page PDF extraction using `pypdf`.
- **Task 2.2:** Create `src/ingestion/chunker.py`:
  - `RecursiveCharacterChunker` class with `chunk_size=500`, `chunk_overlap=50`, and separator hierarchy `["\n\n", "\n", ". ", " ", ""]`.
  - Method `chunk_document(doc_id: str, text: str) -> List[Chunk]` returning canonical `Chunk` objects.

### Wave 3: Vector Store & Retrieval
- **Task 3.1:** Create `src/ingestion/vector_store.py`:
  - `VectorStore` class wrapping FAISS `IndexFlatIP` (cosine similarity with normalized dense vectors) and embedding pipeline with `sentence-transformers/all-MiniLM-L6-v2`.
  - Lazy singleton model initialization to prevent reloading weights on every call.
  - Pure vectorized NumPy fallback if FAISS binary is unavailable in specific OS/Python combinations.
  - Methods: `add_chunks(chunks: List[Chunk])`, `search(query: str, top_k: int = 4) -> List[Chunk]`, `clear()`, `count()`.

### Wave 4: Integration Verification
- **Task 4.1:** Write and run a standalone test script `tests/test_milestone_1.py` that verifies:
  1. Config loading and threshold defaults.
  2. Parsing of sample text/markdown and PDF.
  3. Chunking of text into 500-char slices with 50-char overlaps.
  4. Embedding and vector index search returning relevant top-$k$ `Chunk` instances.
  5. Schema validation of returned `Chunk` objects.

## Verification Criteria
- [ ] All code conforms to strict Python 3.10+ type hints.
- [ ] All returned chunks validate through canonical `Chunk` Pydantic model.
- [ ] No hardcoded keys or credentials.
- [ ] Test script passes 100%.
